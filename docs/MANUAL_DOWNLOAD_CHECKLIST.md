## Rules

- Only save scans you are permitted to keep and display. Prefer public-domain

- Record the exact URL used and the retrieval date.
- When a scan is added: put it in `site/assets/images/`, add an entry to the
  matching provider ledger, then re-run `node scripts/lib_image_merge.js` and
  `node scripts/build-pages.js`.
